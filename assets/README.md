# Wasmer Documentation Assets

This directory contains documentation assets.

`logo.svg` contains the Wasmer wordmark from the inline `Logo` SVG on
[wasmer.io](https://wasmer.io), retrieved on September 17, 2026. The original
view box and path geometry are preserved; website-specific attributes are removed.
`logo-white.svg` uses the same paths with a white fill for dark backgrounds.
The root README uses these SVGs; the PNGs remain for older documentation.
